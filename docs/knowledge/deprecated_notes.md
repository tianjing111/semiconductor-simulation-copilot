# Deprecated Demonstration Notes

This file intentionally contains superseded statements for conflict-detection
tests. It is not an authoritative configuration source.

## Deprecated focus range

An early demo note allowed focus values from -0.10 to +0.10. This range is
deprecated. The canonical range is defined by `parameter_reference.md`.

## Deprecated completion shortcut

An early note treated the presence of any output file as evidence that a task
completed. This shortcut is deprecated. Final acceptance requires the canonical
completion state and artifact checks in `acceptance_rules.md`.
